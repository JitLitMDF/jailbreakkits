## 📖 What Is This?

A collection of jailbreak prompts and full kits targeting modern AI models — primarily **Gemini 3.5 Flash** and expanding. Each kit includes:

- ✅ The exact prompt to paste (copy → paste → go)
- ✅ Ready-to-use example requests
- ✅ Troubleshooting steps if the model refuses
- ✅ Tips for getting better / more detailed outputs

No theory dumps, no walls of jargon. Built for people who want results.

## 🚀 Quick Start

**1.** Pick a kit from the table above  
**2.** Open a **new chat** with the target model  
**3.** Paste the prompt from the kit as your **first message**  
**4.** Wait for the model to confirm the persona  
**5.** Ask for what you want using the example formats in the kit  

That's it. No setup, no tools, no extensions needed.
